# EvidenceFlow v2 learning guide

## 1. status.py
Learn: Enum, rank ordering, why VERIFIED is stronger than LIKELY.

## 2. models.py
Learn: dataclass, frozen objects, tuples, validation, type hints.

## 3. policy.py
Learn: nested helper function, set comprehension, any(), capping-only logic.

## 4. tests/test_policy.py
Learn: unittest, setup, assertions, behavior-driven test names.

## 5. examples/example.py
Learn: importing package objects and running one end-to-end case.

Main limitation: The policy is illustrative and uses synthetic evidence.
